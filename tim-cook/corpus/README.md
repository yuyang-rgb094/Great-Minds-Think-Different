## 🔧 快速开始

### 使用JSON格式
```python
import json

with open('corpus.json', 'r', encoding='utf-8') as f:
    corpus = json.load(f)

# 获取所有领导力相关语录
leadership_quotes = [e for e in corpus['entries'] 
                     if e['category'] == 'leadership']

# 获取所有积极情感的语录
positive_quotes = [e for e in corpus['entries'] 
                   if e['sentiment'] == 'positive']
```

### 使用Markdown格式
直接阅读 `corpus.md` 文件，按主题浏览核心语录。
