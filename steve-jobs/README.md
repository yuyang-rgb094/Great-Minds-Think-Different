# Steve Jobs Agent Corpus（乔布斯智能体前置语料库）

## 项目简介

本语料库旨在为 AI 智能体提供完整的乔布斯思维风格前置语料，涵盖其一生中的核心访谈、演讲、经典语录、思维框架和行为模式。所有内容均以 **Markdown + JSON 双格式** 提供，分别面向人类阅读和机器解析。

## 目录结构

| 模块 | 说明 | 文件数 |
|------|------|--------|
| `01-core-identity/` | 核心身份定义（人设 + 系统提示词） | 4 |
| `02-thinking-frameworks/` | 思维框架（设计、创新、决策、战略） | 8 |
| `03-behavioral-guidelines/` | 行为准则（沟通、领导力、回应） | 6 |
| `04-interviews/` | 访谈语料（9篇核心访谈 + 索引） | 20 |
| `05-quotes/` | 经典语录（8大分类 + 索引） | 18 |
| `06-few-shot-examples/` | 少样本对话示例（6个场景） | 12 |
| `07-knowledge-base/` | 背景知识库（生平、历史、人物等） | 10 |
| `08-quality-control/` | 质量控制（验证、一致性、防幻觉） | 6 |
| `build/` | 构建脚本 | 2 |

## 使用方式

### 作为系统提示词使用

直接加载 `01-core-identity/system-prompt.md` 或 `system-prompt.json` 作为 AI 智能体的系统提示词。

### 模块化加载

按需加载特定模块，例如只需设计哲学部分：
```json
{
  "system_prompt": "...",
  "knowledge": ["02-thinking-frameworks/design-philosophy.json"],
  "few_shot_examples": ["06-few-shot-examples/product-design-scenario.json"]
}
```

### 全量加载

使用 `build/merge-to-single-prompt.json` 合并所有模块为单一系统提示词。

## 语料来源分级

| 级别 | 来源类型 | 可信度 |
|------|----------|--------|
| A级 | 完整访谈文字记录、演讲全文 | 最高 |
| B级 | 权威媒体引用（有视频/音频佐证） | 高 |
| C级 | 传记引用（如《乔布斯传》） | 较高 |
| D级 | 广泛流传但出处模糊 | 中等（需验证） |
